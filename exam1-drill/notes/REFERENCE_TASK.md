Add a section **"Affinity preference: which receptor state each class prefers, and why"** built on the two-state model (`<!--FIG:two-state-->`): receptors sit in equilibrium R ⇌ R*; a drug that binds one state more tightly pulls the equilibrium toward that state. Full agonist: greater affinity for R*, so binding shifts receptors to active (positive efficacy, 100%). Partial agonist: also prefers R*, but shifts less (1–99%). Inverse agonist: highest affinity for R, so binding shifts receptors to inactive (negative efficacy; baseline to 0; loratadine). Neutral antagonist: equal affinity for R and R*, so binding leaves the equilibrium where it is (ε = 0; prazosin, metoprolol). Irreversible antagonist: "highest affinity" because affinity depends on the bond type and the covalent bond is the strongest (phenoxybenzamine); it has no efficacy.

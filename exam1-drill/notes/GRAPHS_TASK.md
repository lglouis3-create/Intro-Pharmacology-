# Graph quiz: a registry of his figures plus questions and miss tags

Goal: a new "Graphs" view where the student picks ONE of his figures (the images in `src/images.json`, which are crops of his PollEV, Jeopardy, review-slide and Part 3 figures) and drills every question written on that figure, getting feedback that names which of his reading questions they skipped.

You create or edit ONLY these files in `/home/user/Intro-Pharmacology-/exam1-drill/src/`:
1. `graphs.js` (new) — `const GRAPHS = [ ... ];` one entry per figure the student can choose. Shape:
   `{key:'pollev-five-drc', alts:['pollev-five-drc-bact','pollev-five-drc-least','pollev-five-drc-correct'], title:'Five dose–response curves A–E (PollEV)', group:'Potency and efficacy'|'Shifts: which curve is which drug'|'Dotted-line figures'|'Affinity and Kd'|'Signal transduction'|'Quantal and therapeutic index'|'Other', source:'PollEV_s.pdf page N' (use the cite already on the questions that use the image), read:[...], method:'...', asks:[...]}`.
   - `alts`: other image keys that are the same figure with a different highlight or crop (group them: pollev-five-drc*, pollev-kd-table*, pollev-abcde-* share the five-curve A–E layout but the drug in the stem differs; keep the abcde ones as ONE entry with alts, since it is one figure he reuses).
   - `read`: 3–6 one-line strings, the figure read in his method (notes/L06.md "three questions": shift from the point of reference? baseline? Emax? symmetrical steps? then "helping or making life more difficult"); for potency/efficacy figures: which curve is most potent (leftmost ED50), most efficacious (highest Emax), partial, and the trap he named. Every line must be true of the actual image: open the question(s) using that image (their imgAlt text describes the figure) and the notes/transcripts before writing.
   - `method`: one sentence, the order of questions to ask yourself on this figure type, in his words where the transcript gives them.
   - `asks`: 2–4 short strings naming the question forms he used or will likely use on this figure (from the bank, PollEV, Jeopardy, the 9/30 review).
2. `q_FIGS.js` (new) — additional questions on these figures so that every GRAPHS entry has at least 5 questions across its key+alts (count the existing ones first: `grep -c "img:'<key>'" q_*.js`). Each new question uses `img:` + `imgAlt:` + `imgCap:` copied from an existing question on the same image, `lecture:'FG'`, `topic:'FG'`, `sub:` one of `'read'|'which'|'why'|'predict'` (you add the topic in course.js: see TOPICS there; add lecture `{id:'FG', deck:'his figures', decks:['PollEV_s.pdf','Pharmacodynamics reviews.pdf','Jeopardy 9/30','Pharmacodynamics-Day_4_&_5_2026s_Part 3.pdf'], label:'Figure drills: his PollEV, Jeopardy and review figures, asked every way he asks', prof:'Gottlieb', exam:1, module:1}` and the matching TOPICS entry with those four subs). Cite format: `'PollEV_s.pdf page N; transcript 9/29'` (must name one of the decks). Formats are his (STYLE.md, notes/POLL_BRIEF.md, notes/L06.md): "DRC B is NE alone; which DRC represents NE in the presence of X", "drug X is most likely", "Which statement is CORRECT/INCORRECT", "Which drug is most potent / most efficacious / a partial agonist", increase/decrease/no effect, "which curve would you NOT see". Vary the drug in the stem across drug-list drugs so the student sees the same figure asked many ways: NE + metoprolol, NE + phenoxybenzamine, histamine + loratadine, GABA + diazepam, NE + duloxetine, NE + epinephrine, dopamine + aripiprazole, albuterol, prazosin, phenylephrine. Keys must follow the figure as he read it (notes/L06.md keys J1–J18; PollEV keys in q_POLLS.js). Keep the longest-option rule (the correct option is never uniquely the longest), no "because/since" in options, every option has a `why`, `teach` 1–4 sentences in his terms, `quote` where the transcript has one.
3. Every existing question with an `img:` field (q_POLLS.js, q_L06.js, q_JEOP.js) and every new one: add to each WRONG option a field `miss:` with one of `'shift'|'baseline'|'emax'|'symmetry'|'direction'|'potency'|'efficacy'|'affinity'|'class'|'steps'|'ti'|'read'` naming the reading question the student skipped if they chose it ('direction' = helping vs making life more difficult / left vs right; 'class' = knows the curve but not which drug class produces it; 'steps' = signal-transduction order; 'read' = misread the axis or legend). Verbatim items (tags include 'pollev', sub 'verbatim') may take `miss` tags; do not change any other field of them.

Rules: no invented numbers (reuse only values already on the image, in the bank or in notes); literal language; single quotes escaped as \'; no backticks or `${` in bank strings. Run `python3 build.py && node test.js && node style_check.js` until clean (browser_test.js may fail until the Graphs view exists; ignore only that).
